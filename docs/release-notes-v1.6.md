# VoltWarden v1.6

这一版主要优化了后台耗电。菜单关闭后，功率流动画会停止刷新；电池状态稳定时，后台采样和诊断日志也会放慢。打开菜单后仍保持原来的 30 帧功率动画和快速数据刷新，充电控制逻辑没有改动。

我在自己的 M4 Pro、macOS 27 上做了短时间对比：旧版主进程在菜单未操作时约占一个 CPU 核心的 15%–17%，更新后约为 0%–1%。这不是按瓦数测出的续航提升，也不能保证每台 Mac 都有相同比例的变化。

下载 `VoltWarden-v1.6-arm64.zip`，解压后把 VoltWarden.app 放进“应用程序”；旧版正在运行的话，先从菜单栏退出再替换。首次打开和后台助手授权步骤见 README。校验值见 `VoltWarden-v1.6-arm64.sha256`。

目前只提供 Apple 芯片版本；我只在自己的 M4 Pro、macOS 27 上验证。安装包使用 Apple Development 签名，尚未经过 Apple 公证，首次打开可能需要在“系统设置 → 隐私与安全性”里手动允许。启用充电管理还需要系统批准后台助手。其他机型或系统版本的充电控制表现仍需实机验证。
